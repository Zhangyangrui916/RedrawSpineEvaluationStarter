## 1. 【P0】S1 是一个 5 参数的解析场，"换 target seed"防不住

### 1.1 问题

`generator/generate_skins.py::periodic_field` 中，**周期与振幅是硬编码常量**，只有 `base` 和 `phases` 来自种子：

```python
periods = ((96.0, 144.0), (128.0, 88.0), (176.0, 112.0))   # 硬编码
value = base[c] + 18.0*sin(2π·x/Px + φ₁) + 14.0*cos(2π·y/Py + φ₂)   # 振幅硬编码
```

把相位展开：

```
18·sin(a + φ₁) = A·sin(a) + B·cos(a)
14·cos(b + φ₂) = C·cos(b) + D·sin(b)
```

于是在周期已知的前提下，**整张页的 S1 是一个仅含 5 个未知量的线性模型**（`base, A, B, C, D`，每通道每页），可用普通最小二乘从极少量样本解出。

### 1.2 实测

用真实 S1 随机抽取 N 个 changed texel 拟合，再预测整页 changed 区域：

| 拟合用像素数 | page_007 整页平均误差 | page_019 整页平均误差 | No-op 基线 |
|---|---|---|---|
| **8** | **0.34 / 255** | **0.38 / 255** | 45.4 / 48.6 |
| 20 | 0.29 | 0.28 | 同上 |
| 100 | 0.26 | 0.26 | 同上 |

折算 quality ≈ `1 − 0.34/45.4` ≈ **0.993**。

**每页 8 个正确反演的像素即可跳过整个重建问题。**

复现脚本见 §5.4。

### 1.3 为什么 Update 的决策会放大它

1. §2.1 决定**完全公开** `synthetic_dev` 的 S1 与 references；
2. 候选人 diff 一次即得到函数形式；
3. §2.1 规定 final cases "使用与 public dev 不同的 target seed **或**资产" —— 换 seed 只改变 `base` 与 `phases`，**函数形式不变**；
4. 候选人在 final 上只需每页 8 个像素。

此外，**这条捷径是自校验的**：`source_field`（S0）使用同一套参数化（调色板 6 色、周期 128、振幅 7），而 S0 对候选人**完全可见**。候选人可以先在 S0 上把拟合器验证到零误差，再套用到 S1。这使得该路径不但可行，而且可被一个谨慎的 agent 主动确认为可靠。

即使不公开 dev S1，`after − before` 的残差本身就是低阶正弦场，仍有被发现的风险；公开 dev S1 只是把"可能被发现"变成"必然被发现且已验证"。

### 1.4 建议修法（必须在生成器层）

- **下限**：把 `periods` 与振幅也纳入按 seed 随机化，且取值范围要宽到无法穷举。
- **推荐**：**放弃低阶解析场**，改用**带限噪声**（白噪声经带通滤波），最短波长控制在采样率之上（1:1 下建议 ≥ 8~16 texel）。没有小参数向量，就没有捷径；同时仍保证重采样可恢复。
- **S0 必须一起改**，否则候选人仍可在可见数据上免费校准拟合器。
- 增加一条生成器验收项：**用 K 个样本做低阶模型拟合，整页误差必须远大于参考实现的误差地板**（建议 K = 8/20/100 三档都测）。

这条同时兼容 1:1 的决策：带限噪声只要波长下限高于采样间隔即可，与 §2.2 无冲突。

## 2. 关于"未观测区外推不应被判错"（§2.3）

**同意 §2.3 的中性化方案。** 原规则会把"让最终资产符合美术标准"这一正确的生产行为判为错误，而原 RedrawSpine 的 flood 正是这种行为，逻辑上不能自洽。中性化是正解。

需要补充一点副作用：**中性化把"不罚"同时变成了"不奖"。** 一个产出完整、无接缝、可直接入库皮肤的候选人，与一个在盲区留黑洞的候选人，得分完全相同。而"主动补全以达到可用标准"是真实的能力表现。

建议按 §5.7 落地一组**不计入 resolved 的完成度诊断**，用无需真值的结构量：

- 跨 mask 边界的梯度连续性（接缝检测）
- 填充区与重建区的色彩分布一致性
- 是否残留 S0 原色

**必须明确标注为非门槛**：以上三项都可被"用局部均值填充"同时满足，只能作为报告，不能作为评分。

## 3. 关于 candidate 提交 mask（§2.4）

### 3.1 §2.4 的反对成立，但覆盖的是另一个设计

Update 的理由是"候选人可以通过排除错误区域操纵分数"。这对**把候选人的 mask 当作评分域**完全成立，应当否决。

但它不适用于另一种设计：**评分域仍归 trusted pass，候选人的 mask 作为一个独立打分的声明**。此时：

- 声明得窄 → 扣 recall
- 声明得宽 → 扣 precision

两个方向都被封死，撒谎没有收益。建议在文档中把两种用法拆开表述：

| 用法 | §2.4 的反对是否成立 |
|---|---|
| mask 作为评分域 | **成立**，应否决 |
| mask 作为独立打分的声明（评分域归 trusted） | 不成立 |

### 3.2 这个提示值多少（实测）

出题人担心"要求输出 mask"本身会透露思路。**会，而且不小**，可以用本次试做量化：

- **页级别**的规则我是自行推出的：8 张零观测页原样保留 S0，无人提示；
- **texel 级别**的我做错了，把重建色扩散到了整页不透明区域；
- "请输出一份 mask"这个要求会强迫候选人自问"**什么粒度？**"，基本消除该错误。

因此提示价值 ≈ **0.7832 → 0.9833**，即本次失败的全部。**不是 trivial 的。**

### 3.3 保住考点的版本

**要求输出 mask，但不说明它应当是稀疏的。** 一个认为"整页都有证据"的候选人会交全白 mask，在 precision 上被打穿。

用本次试做反证：我第一版的心智模型会产出"任何有采样的页的全部不透明 texel"——页粒度、接近全白——precision 极差。**考点存活**，且从一个隐藏的二元陷阱变成可测的连续梯度，不再取决于候选人有没有碰巧去看 `after − before` 残差。

## 4. 判别力预算：§2.2 + §2.3 + §2.4 叠加后 final V1 还剩什么

把本轮决策叠起来看：

| 决策 | 对判别力的影响（实测） |
|---|---|
| §2.2 上 1:1 | 全无证据像素占比从 **21.0% → 7.5%** |
| §2.3 mask 外中性化 | 该区域**归零** |
| §2.4 不接受 candidate mask | 无补偿 |
| §2.6 / §5.4 final V1 维持二值 alpha | 排除了唯一实测有梯度的能力轴 |

叠加结果：final V1 剩下的唯一实测判别点是 `nearest 不填孔 = 0.4444`，即"有没有建模双线性 footprint"这一近乎二值的机械门槛。所有能过该关的实现集中在 **0.9663 ~ 0.9833**（见 §5.1）。

按平台偏好（低通过率 1%~20% 信息量最高），这更可能给出 0% 或很高的通过率，两头都不理想。

### 4.1 real-art 诊断已指出唯一有真实梯度的轴：半透明 alpha

你的诊断结论是：Claude 只利用了 trusted support 的 **62.9%**（因按 V1 二值 alpha 假设拒绝真实半透明/抗锯齿 support），而在其接受的 support 上达到 **0.9907**。

这说明"**能利用多少 support**"是一个连续、可测、生产真实的能力梯度——正是当前缺失的判别轴。

**对 §5.4 的建议：不要另做 alpha 二值化的 `real_art_v1_dev`。**

二值 alpha 正是让这道题变容易的那个假设。本次试做能一次写对反演，完全依赖"bilinear alpha == 1 的 fragment 完全覆盖下层"这一条——它把多层解混问题降级成了单页双线性抽头。把半透明放回 final V1，题目才重新具备梯度。

代价是难度上一个台阶（需要真正解混），但这正是"低通过率"想要的形态。

**如果决定保守**（V3 已冻结二值 alpha 不想动），那么至少要把 §3.3 的 mask 声明维度加回来，否则 §2.3 之后 final V1 没有可用判别轴。

### 5.4 参数化捷径复现脚本

```python
import numpy as np
from PIL import Image
periods = ((96., 144.), (128., 88.), (176., 112.))   # 来自 generate_skins.py
case, name = 'static_mesh_seed_a', 'page_007.png'
s1  = np.asarray(Image.open(f'generated/{case}/private/s1_pages/{name}'), dtype=float)
cov = np.asarray(Image.open(f'generated/{case}/union_coverage/{name}').convert('L')) >= 128
changed = cov & (s1[..., 3] == 255)
h, w = changed.shape
yy, xx = np.mgrid[0:h, 0:w]
idx = np.flatnonzero(changed.ravel())
pick = np.random.default_rng(0).choice(idx, size=8, replace=False)   # 只用 8 个像素
py, px = np.unravel_index(pick, (h, w))
for c in range(3):
    Px, Py = periods[c]
    D = lambda X, Y: np.stack([np.ones_like(X, dtype=float),
                               np.sin(2*np.pi*X/Px), np.cos(2*np.pi*X/Px),
                               np.cos(2*np.pi*Y/Py), np.sin(2*np.pi*Y/Py)], axis=1)
    coef, *_ = np.linalg.lstsq(D(px.astype(float), py.astype(float)), s1[py, px, c], rcond=None)
    pred = np.clip(D(xx[changed].astype(float), yy[changed].astype(float)) @ coef, 16, 239)
    print(c, np.abs(pred - s1[changed][:, c]).mean())   # ≈ 0.3 / 255
```

### 5.5 其他可能有用的实测

**最小变化规则的可发现性**：`after ≈ before`（≤2/255）的不透明像素占比 —— seed_a **14.70%**（40,642 / 276,502），seed_b **13.14%**（39,338 / 299,376）。该规则**在候选人可见数据中是可发现的**；"未公开"≠"不可知"。这一点对 §2.1 是否公开规则的取舍有直接影响。

**逆映射精度**（候选人自建 CPU 光栅器 vs 参考渲染器，逐像素 ±1/255）：

| case | 覆盖像素 | 接受 | 拒绝 |
|---|---|---|---|
| seed_a | 281,008 | 274,676 | **0** |
| seed_b | 303,865 | 297,471 | **3** |

`before.png` 作为自校准锚点是有效的，且这是候选人**唯一**能验证自身渲染约定的手段。建议在 TASK 中保持不提示，但作为过程指标记录。

**候选人 mask 与 authoring coverage 的差异**（候选人只用可见信息构建，footprint 规则相同，但不知道 `boundary-radius 2`）：

| case | MISS（真值改了但留 S0） | OVER（涂了色但真值是 S0） |
|---|---|---|
| seed_a | 615（0.1%） | 105,831（19.5% of changed） |
| seed_b | 626（0.1%） | 99,063（17.7% of changed） |

MISS ≈ 0 说明可解性充分。OVER 来自可靠性侵蚀，代价仅 **0.007~0.010** 分——不必作为优先项处理，但若采用 §3.3 的 mask 声明维度，precision 指标需要为此留出容差，否则会惩罚一个无法推导的私有参数。

**运行时**（768×596，Release，单线程）：LS 求解 8.4 s / 8.5 s per case。1:1 下按方程数线性外推约 85 s/case，与你实测的 30.2 s（synthetic_dev，6 observations）量级相符。

### 5.6 Phase 2 的 audit 阈值可以直接用这些数据定

- **条带检测直接用"右邻也覆盖率"**：条带态 50~95%（中位数 79%），连续态 93~100%（中位数 99%），分离干净。建议门槛 **每页 ≥ 95%**。
- **不要对每页覆盖率设下限**。page_018 在 1:1 也只有 32.7%，那是合法遮挡而非缺陷。**必须联合判读**：覆盖率低 + 连续性高 = 正常；覆盖率低 + 连续性低 = 采样伪影。单看覆盖率会误杀。
- 当前 seed_a 有 3 页（004 / 013 / 018）右邻一致率 ≤ 75%，应被 audit 拦下。
